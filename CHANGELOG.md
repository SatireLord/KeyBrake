# Changelog

## 0.1.0

First experimental prototype on the implementation branch.

- Native macOS menu-bar failsafe with typed command execution and exact process identity.
- Atomic incident and recovery storage with original/applied/current restore rules.
- Privileged helper source for administrator-required network, sharing, and verified launchd stops.
- MIT license, security policy, contributing guide, and capability matrix.

Unsigned local builds only. Live helper approval, Developer ID signing, live TCC, live network isolation, and mouse-only UI proof remain external.
