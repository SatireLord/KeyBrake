# Safe portfolio demonstration

1. Build the Debug app and launch it from a human-controlled local Mac session.
2. Open the menu bar item and show the exact status row and action ordering.
3. Run the deterministic unit tests, which use fake command runners and never mutate the host network or real TCC decisions.
4. Demonstrate `Stop Skynet Locally` with a fake Espanso command trace or a disposable Espanso installation only after confirming the user configuration is backed up and untouched. Use `Restart Espanso` as a separate action.
5. Demonstrate remote-target sequencing with the harmless fixture definitions in the tests. Do not enroll a real support tool for a portfolio recording unless the machine has an independent recovery path.
6. Demonstrate privacy reset command formation with a disposable fixture bundle identifier and a fake runner. Never reset Terminal, Codex, Cursor, Espanso, KeyBrake, or another daily-use app merely to create a receipt.
7. Use read-only network inventory for the normal demo. Show the recovery contract and explain that a full live isolation test requires a separately staged session because it intentionally disconnects the active network.
8. Seed `CurrentRecovery.json` with a test fixture, relaunch the app, show `Recovery Required`, open the recovery panel, and demonstrate the mouse-only quit warning.

The demo must say `Network Isolated` or `Partial Isolation`, not that the computer is safe or that all remote access is eliminated.
