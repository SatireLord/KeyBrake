# Code of conduct

KeyBrake is experimental macOS recovery software. Contributors and users are expected to keep people, machines, and claims safe.

## Expected behavior

- Be respectful. Harassment, intimidation, and personal attacks are not allowed.
- Keep claims honest. Do not describe KeyBrake as antivirus, as a guarantee that remote access is gone, or as signed/notarized without a receipt.
- Do not ask others to run live network isolation, VPN disconnect, sharing mutation, or TCC reset on a machine without a known recovery path.
- Do not request or share exploits against the privileged helper, recovery snapshot, or authorization boundary in public issues.

## Reporting

- Conduct issues that are not security defects: open a private maintainer contact through GitHub, or use a GitHub issue only when no vulnerability is involved.
- Security defects: follow [`SECURITY.md`](SECURITY.md). Do not file a public issue for exploitable helper, recovery, or authorization bugs.

## Enforcement

The maintainer may edit or close contributions that violate this policy, including pull requests that add live-host mutation without a documented recovery path or that overclaim unverified capabilities.
